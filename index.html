⚿ YouTube Data API 키 (조회 전용·선택)

여기에는 AIza로 시작하는 API 키만 입력하세요. 키는 이 브라우저의 localStorage에 저장되고 조회 요청 때 Google API로 전달됩니다. 조회수 수집에는 API 키가 필요하지만, 영상 업로드에는 API 키가 아니라 서버의 n8n OAuth 연결이 필요합니다.

GOCSPX-…는 API 키가 아니라 OAuth Client Secret입니다.
이 화면이나 소스 코드에 절대 입력하지 마세요. 외부에 공개했다면 Google Cloud에서 즉시 폐기·재발급해야 합니다.

데이터 원칙

추정 조회수·가짜 프로필을 만들지 않습니다. 공식 API가 주지 않는 값은 비워두며, YouTube와 제휴하지 않고 다운로드·광고 차단·자동 조작 기능은 없습니다.

⚑ 배포 안내

상단의 앱 설치를 누르면 갤럭시에서 독립 실행되는 PWA로 설치됩니다. 앱은 채팅·사진 업로드·설정·상태 확인용 리모컨입니다.

Android 앱은 절전 정책 때문에 24시간 작업을 보장할 수 없고 폰이 꺼지면 정지합니다. 실제 영상 제작·예약 업로드는 이 저장소의 n8n + PostgreSQL + FFmpeg worker가 항상 켜진 VPS에서 계속 수행합니다.

서버에서 ./scripts/init-env.sh 실행 → 새 Google OAuth 연결 → Manual Test → 워크플로 Publish 순서로 설정하세요.

OAuth Client Secret은 브라우저나 GitHub에 넣지 않고 n8n의 암호화 credential 저장소에만 보관합니다. 자세한 절차는 저장소의 README.md를 확인하세요.
